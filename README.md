# Nari Nikhar

Website for Nari Nikhar, a women's clothing store in Naya Ganj, Hathras.
Live at https://prashanttyagi3112.github.io/narinikhar/

- `index.html` is the whole site. It is generated by `build.py`: edit outfit names, prices or text there, then run `python3 build.py site index.html`.
- `images/` holds the outfit photos.
- `collections.html`, `our-story.html`, `visit.html` forward old links to the matching section.
