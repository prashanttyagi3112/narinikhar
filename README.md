# Nari Nikhar — Hathras boutique website

A responsive, multi-page static website for the Nari Nikhar women's fashion boutique in Hathras. Pages: Home, Collections, Our story and Visit us. It uses plain HTML/CSS/JavaScript, so there is no build step and GitHub Pages can serve it directly.

## Before launch

- Confirm the phone number, address, opening hours and ₹300 video-call booking policy.
- Replace the sample fashion photos with images you own or have permission to use. The current demo images load from Unsplash and require an internet connection.
- Review all collection descriptions and add current product/stock details if you want them shown.

## Free hosting on GitHub Pages

1. Create a public GitHub repository named `narinikhar` (or another name you prefer).
2. Upload the **contents** of this folder to the repository's root so `index.html` is at the top level.
3. In the repository, open **Settings → Pages**. Set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub will show the live `https://YOUR-USERNAME.github.io/narinikhar/` address on that page after deployment.
5. Later, add a custom domain in the same Pages settings and follow GitHub's DNS instructions at your domain registrar.

This is a static site; it does not take payments or store orders. WhatsApp links start a conversation with the boutique.
